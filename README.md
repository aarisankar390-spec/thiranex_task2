# Aari Sankar — Advanced CSS3 Portfolio

## Files
- `index.html` — semantic portfolio structure
- `style.css` — CSS Grid, Flexbox, CSS variables, mobile-first media queries and visual styling
- `script.js` — responsive navigation and persistent light/dark mode

## Run
Open `index.html` in a browser. For local development, you can also use VS Code Live Server.

## Before submitting
1. Replace `yourmail@example.com` with your actual email.
2. Update the LinkedIn link to your profile.
3. Check the project links and edit project descriptions if needed.
4. Test at mobile, tablet and desktop widths.
